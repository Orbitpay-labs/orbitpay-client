What it solves

Most users can send Stellar funds. Fewer know how to fund smart accounts cleanly.

OrbitPay sits between merchant apps, Stellar wallets, and Soroban smart accounts. It turns the technical route into a simple product experience: amount, asset, destination, memo, and payment state.

Developer kit

Small API surface, clear integration story.

import { OrbitPay } from "@orbitpay/sdk";

const session = await OrbitPay.createFundingSession({
  network: "testnet",
  destination: "CC4V...N9QP",
  asset: "USDC",
  amount: "45.00",
  successUrl: "https://merchant.app/paid"
});
